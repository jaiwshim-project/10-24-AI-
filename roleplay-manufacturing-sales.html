📋 롤플레이 사례 선택

💡 사례 선택 가이드

1️⃣ 난이도 확인
⭐⭐⭐ 초급: 기본 상황
⭐⭐⭐⭐ 중급: 복잡한 변수
⭐⭐⭐⭐⭐ 고급: 위기 상황
2️⃣ 사례 읽기
상황·목표·챌린지를 꼼꼼히 읽고 실제 상황처럼 준비하세요
3️⃣ 카드 클릭
사례 카드를 클릭하면 선택됩니다. 이후 시나리오를 선택하고 녹음을 시작하세요
🎯 실전 팁
• 처음이라면 ⭐⭐⭐ 난이도부터 시작하세요
• 실제 업무와 유사한 사례를 선택하면 학습 효과가 높습니다
• 4번째 "나만의 실제 사례"는 본인이 직면한 실제 상황을 입력할 수 있습니다
• 녹음 전에 사례 내용을 2-3번 읽고 역할을 머릿속으로 리허설하세요

아래 사례 중 하나를 선택하여 롤플레이를 진행하세요.

🏭 신규 거래처 납품 제안
📍 상황: 중견 제조사 구매팀장에게 월 1억원 규모 부품 납품 제안, 경쟁사 3곳 비교 중 🎯 목표: 샘플 테스트 승인 + 공장 방문 일정 확보 ⚡ 챌린지: 기존 거래처와 5년 관계, 품질·가격·납기 삼박자 요구, 신뢰 부족 ✅ 기대결과: 샘플 발송 동의 + 공장 방문 약속 + 구매팀장 신뢰 확보 난이도: ⭐⭐⭐⭐
💰 가격 재협상 요청 대응
📍 상황: 2년 거래처가 원자재 가격 하락 이유로 단가 10% 인하 요구 🎯 목표: 거래 유지하면서 3% 인하로 합의 ⚡ 챌린지: 경쟁사 견적서 제시, 품질 문제 지적, 계약 해지 압박 ✅ 기대결과: 3% 인하 합의 + 3년 장기 계약 체결 + 추가 품목 납품 기회 난이도: ⭐⭐⭐⭐⭐
📦 납기 지연 사과 및 보상
📍 상황: 중요 거래처 납품 2주 지연, 고객사 생산 라인 일부 중단 🎯 목표: 사과 수용 + 보상 조건 합의 + 거래 유지 ⚡ 챌린지: 고객사 극도 분노, 배상금 요구, 경쟁사 영업 활동 중 ✅ 기대결과: 보상 합의 + 신뢰 회복 + 재발 방지 시스템 약속 난이도: ⭐⭐⭐
✏️ 나만의 실제 사례
📍 상황: 본인의 실제 제조업 영업 사례를 입력하세요 🎯 목표: 맞춤형 롤플레이 ⚡ 챌린지: 사용자 설정 ✅ 기대결과: 실전 상황 대응 능력 향상 난이도: 사용자 설정
