프로그램 설명

RoleCoach AI는 AI 기반 롤플레이 시뮬레이션을 통해 사용자의 커뮤니케이션 스킬을 향상시키는 웹 기반 코칭 플랫폼입니다. 병원 상담, 영업 세일즈, 정치 선거, 취업 면접, 스타트업 피칭 등 5개 분야에 특화된 AI 코치가 실시간으로 대화를 진행하고, 사용자의 스피치를 분석하여 정량적 피드백을 제공합니다.

창작 목적

  • 실전 중심 학습: 이론이 아닌 실제 대화 시나리오를 통한 체득식 훈련
  • 분야별 전문화: 각 분야의 세계적 전문가 페르소나를 모델로 한 AI 코치 제공
  • 정량적 분석: 말하기 속도, 필러 워드, 톤, 프레임워크 준수도 등을 수치화
  • 한국어 특화: 한국어 필러 워드 탐지, 존댓말 일관성 분석 등 한국 시장 맞춤 기능
  • 접근성: 로그인 없이 브라우저에서 즉시 사용 가능한 웹 플랫폼

벤치마킹

글로벌 1위 스피치 코칭 플랫폼 Yoodli AI의 핵심 기능을 벤치마킹하고, 한국 시장에 특화된 기능(한국어 필러 워드 탐지, 존댓말 분석, SPIN/Insight Selling 통합, 5단계 설득 로드맵)을 추가했습니다.

2. 기능 명세

🎤 실시간 AI 롤플레이

AI가 고객, 면접관, 유권자 등 다양한 역할을 수행하며 실전처럼 대화를 진행합니다. 사용자의 응답에 따라 동적으로 시나리오가 변화합니다.

📊 스피치 메트릭 분석

말하기 속도(WPM), 필러 워드 횟수, 톤(자신감/명료도/에너지), 프레임워크 준수도를 정량 분석하여 시각화합니다.

👨‍🏫 전문가 AI 코치

Neil Rackham(SPIN Selling), Matthew Dixon(Insight Selling), Simon Lancaster(정치 연설), Gayle McDowell(면접), Jason Calacanis(피칭) 등 세계적 전문가를 모델로 한 AI 페르소나가 분야별 코칭을 제공합니다.

🎯 프레임워크 학습

SPIN Selling(Situation→Problem→Implication→Need-Payoff), STAR 프레임워크(Situation→Task→Action→Result), 5단계 설득 로드맵 등 검증된 커뮤니케이션 방법론을 체득합니다.

🎙️ 녹음 & 재생

세션을 녹음하여 반복 청취하고 자가 평가할 수 있습니다. 녹음 파일은 브라우저 로컬 스토리지에 저장됩니다.

📈 진도 추적 대시보드

개인별 학습 이력, 분야별 평균 점수, 점수 진행 추이를 시각화하여 개선 추이를 확인합니다.

🇰🇷 한국어 필러 워드 탐지

"어", "음", "저기", "그러니까", "뭐", "막" 등 한국어 특화 필러 워드를 정확하게 탐지하고 타임스탬프를 제공합니다.

🎓 존댓말 일관성 분석

비즈니스 상황별 높임법 준수도를 평가하고, 반말/존댓말 혼용 사례를 자동으로 감지합니다.

🏥 5단계 설득 로드맵 (병원 상담)

공감 형성 → 문제 인식 → 해결책 제시 → 신뢰 구축 → 행동 유도 단계를 자동으로 채점합니다.

💼 SPIN/Insight Selling 통합 (영업)

SPIN Selling과 Insight Selling 기법을 통합 적용하여 B2B/B2C 영업 역량을 강화합니다.

5개 분야별 시나리오

  • 병원 상담: 신규 환자 상담, 치료 계획 설명, 비용 상담, 재내원 환자 관리
  • 영업 세일즈: 신규 고객 발굴, 니즈 파악 질문, 가치 제안, 반론 처리 & 클로징
  • 정치 선거: 유세 연설, 공약 발표, 토론회 대응, 유권자 소통
  • 취업 면접: 자기소개, 경험 설명(STAR), 강점/약점 질문, 상황 질문 대응
  • 스타트업 피칭: 엘리베이터 피치(30초), 투자자 피칭(5분), 데모데이 발표, Q&A 세션

3. 시스템 구조

클라이언트 아키텍처

RoleCoach AI는 순수 웹 기반 SPA(Single Page Application) 구조로 설계되었습니다. 서버 없이 클라이언트 사이드에서 모든 로직이 실행되며, 외부 API는 Gemini AI만 사용합니다.

기술 스택

  • Frontend: HTML5, CSS3 (Premium White Theme), Vanilla JavaScript (ES6+)
  • AI API: Google Gemini API (스피치 분석, 롤플레이 대화 생성)
  • 로컬 스토리지: LocalStorage (세션 관리, 학습 이력 저장, 녹음 파일 저장)
  • 녹음: Web Audio API (MediaRecorder, getUserMedia)
  • 차트: Canvas 2D API (분야별 성과, 진행 추이 시각화)

파일 구조

데이터 흐름

  1. 세션 시작: 사용자가 분야 선택 → 시나리오 선택 → 롤플레이 페이지 진입
  2. 대화 진행: 사용자 발화 → 음성 녹음 → Gemini API 전송 → 음성→텍스트 변환 → AI 응답 생성
  3. 분석: 녹음 종료 → Gemini API 호출 (스피치 분석) → 결과 LocalStorage 저장 → 피드백 페이지로 이동
  4. 대시보드: LocalStorage에서 학습 이력 조회 → 통계 계산 → Canvas 차트 렌더링

4. 독창적 요소

1️⃣ 한국어 필러 워드 탐지 시스템

기존 글로벌 스피치 분석 도구는 영어 필러 워드("uh", "um", "like")만 탐지합니다. RoleCoach AI는 한국어 특화 필러 워드("어", "음", "저기", "그러니까", "뭐", "막", "아", "좀")를 정확하게 탐지하고, 각 발화 시점의 타임스탬프를 제공합니다.

독창성: 한국어 음성 인식 + 형태소 분석 + 문맥 기반 필터링을 통합한 독자적 알고리즘

2️⃣ 존댓말 일관성 분석

비즈니스 상황(병원 상담, 영업, 면접)에서 존댓말/반말 혼용은 신뢰도를 낮춥니다. RoleCoach AI는 문장 단위로 높임법 사용 여부를 분석하고, 일관성 점수를 제공합니다.

독창성: 한국어 경어법 규칙 + AI 학습을 결합한 실시간 존댓말 분석 엔진

3️⃣ SPIN/Insight Selling 통합 프레임워크

Neil Rackham의 SPIN Selling과 Matthew Dixon의 Insight Selling을 하나의 프레임워크로 통합하여, B2B 영업 상황에서 자동으로 단계별 진행도를 채점합니다.

독창성: 두 방법론의 핵심 요소를 추출하고 한국 시장에 맞게 재구성한 하이브리드 모델

4️⃣ 5단계 설득 로드맵 (병원 상담 전용)

치과병원 상담실장을 위한 독자적 프레임워크로, 공감 형성 → 문제 인식 → 해결책 제시 → 신뢰 구축 → 행동 유도 단계를 정의하고 각 단계별 핵심 질문과 화법을 자동으로 평가합니다.

독창성: 치과병원 상담 현장에서 검증된 프로세스를 AI 코칭 시스템으로 구현

5️⃣ 분야별 AI 코치 페르소나

각 분야의 세계적 전문가를 모델로 한 AI 페르소나를 정의하고, 해당 전문가의 코칭 스타일과 질문 방식을 재현합니다.

  • 병원 상담: Dr. Michael Unger (환자 커뮤니케이션 전문가)
  • 영업 세일즈: Neil Rackham + Matthew Dixon (SPIN + Insight Selling 창시자)
  • 정치 선거: Simon Lancaster (영국 정치 연설 작가)
  • 취업 면접: Gayle McDowell (Google/Microsoft 면접관, "Cracking the Coding Interview" 저자)
  • 스타트업 피칭: Jason Calacanis (엔젤투자자, "Angel" 저자)

독창성: 전문가의 저서, 인터뷰, 강연 내용을 분석하여 AI 프롬프트로 재구성

6️⃣ 서버리스 클라이언트 전용 아키텍처

백엔드 서버 없이 클라이언트 사이드에서 모든 기능을 구현하여, 인프라 비용 제로로 무제한 확장이 가능합니다. 사용자 데이터는 브라우저 LocalStorage에만 저장되어 개인정보 보호가 강화됩니다.

독창성: Gemini API + LocalStorage + Web Audio API를 조합한 독립형 웹 플랫폼

7. 시스템 구조도

🏥 병원 상담 💼 영업 세일즈 🎤 정치 선거 📝 취업 면접 🚀 스타트업 실시간 롤플레이 (roleplay-*.html) 🎤 음성 녹음 (Web Audio API) MediaRecorder + getUserMedia 🤖 AI 대화 생성 Gemini API (실시간 응답) AI 분석 엔진 (common.js - analyzeSpeech) 필러 워드 탐지 어, 음, 저기, 그러니까 스피치 메트릭 속도, 톤, 자신감 프레임워크 준수도 SPIN/STAR/5단계 로드맵 AI 코치 피드백 (feedback.html) 점수, 개선점, 재생, 상세 분석 학습 대시보드 (dashboard.html) 통계, 진행 추이, 분야별 성과 차트 💾 LocalStorage rolecoach_session (세션 관리) roleplay_history (학습 이력) audio_recordings (녹음 파일) 🧠 Gemini API 음성→텍스트 AI 대화 생성 스피치 분석

데이터 흐름 설명

  1. 사용자 진입: 웹 브라우저에서 index.html 접속
  2. 분야 선택: 5개 분야 중 하나 선택 (병원/영업/정치/면접/스타트업)
  3. 롤플레이 시작: 시나리오 선택 → 음성 녹음 시작 → Gemini API 호출 → AI 응답 생성
  4. 스피치 분석: 녹음 종료 → Gemini API 분석 → 필러 워드/속도/톤/프레임워크 평가
  5. 피드백 표시: feedback.html에서 점수, 개선점, 녹음 재생, 상세 분석 제공
  6. 데이터 저장: 분석 결과를 LocalStorage에 저장 (roleplay_history)
  7. 대시보드 업데이트: dashboard.html에서 통계 계산 → Canvas 차트 렌더링

기술적 특징

  • 서버리스: 백엔드 서버 없이 클라이언트 사이드에서 모든 로직 실행
  • 오프라인 우선: LocalStorage를 활용하여 네트워크 없이도 대시보드 조회 가능
  • 확장성: 분야 추가 시 HTML 파일 하나만 추가하면 됨 (공통 모듈 재사용)
  • 보안: 사용자 데이터는 브라우저 로컬에만 저장 (서버 전송 없음)
