━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. API 키 발급:
   https://console.anthropic.com/settings/keys
   → "Create Key" 클릭
   → sk-ant-api03-xxxxx 형식의 키 복사

2. .env.local 파일 수정:
   notepad .env.local

   내용:
   ANTHROPIC_API_KEY=sk-ant-api03-xxxxx
   (your-api-key-here를 실제 키로 교체)

3. Vercel Dev 재시작:
   Ctrl + C (서버 중지)
   npx vercel dev (다시 실행)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "vercel: command not found"
→ npm install -g vercel

❌ "Port 3000 is already in use"
→ npx vercel dev --listen 3001

❌ "Failed to fetch"
→ .env.local에 API 키 확인 → Vercel Dev 재시작

❌ 마이크 권한 오류
→ Chrome 주소창 왼쪽 자물쇠 → 사이트 설정 → 마이크 허용
