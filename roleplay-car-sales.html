🚗 신차 전시장 첫 방문 고객 ⭐⭐⭐
30대 직장인 부부, 첫 자녀 출산 예정으로 첫 차 구매
📋 상황
30대 직장인 부부, 첫 자녀 출산 예정으로 첫 차 구매. 예산 3천만원, SUV 선호하나 브랜드 지식 전무. 타사 전시장 2곳 방문 후 비교 중. 당일 계약 의사 없음, "구경만" 강조.
🎯 목표
30분 상담으로 고객 니즈 파악 (안전>연비>디자인 우선순위) → 2개 모델 시승 예약 확보 → 견적서 2종 제공 → 다음 주 재방문 약속 + 카톡 추가
⚡ 챌린지
"구경만" 고객을 시승 고객으로 전환 / 타사 대비 우리 차 장점 각인 시키되 과도한 영업 거부감 방지 / 예산 3천만원에 맞는 모델 vs 상위 모델 제안 균형 / 부부 의견 차이 조율
✅ 기대결과
3일 내 시승 완료 + 일주일 내 재방문 + 2주 내 계약 전환율 60% + 타사 견적 비교 시 우위 확보
💰 가격 협상 고객 ⭐⭐⭐⭐
40대 자영업자, 경쟁 브랜드 견적서 제시하며 가격 맞춰달라 요구
📋 상황
40대 자영업자, 현대 SUV 관심, 견적 4,200만원 제시받음. 경쟁 브랜드(기아) 3,800만원 견적서 제시하며 가격 맞춰달라 요구. 옵션은 동일, 당일 계약 가능하다며 압박. 본사 할인 한도 3%.
🎯 목표
1시간 협상으로 가격 외 가치 부각 (A/S 우수성, 리세일 밸류, 브랜드 선호도) → 최대 할인 3% (126만원) + 순정 액세서리 100만원 제공 → 당일 계약 체결 4,074만원
⚡ 챌린지
400만원 차이를 126만원 할인으로 설득 / 경쟁사 견적 진위 확인 / "다른 딜러는 더 깎아준다" 주장 대응 / 당일 계약 압박 역이용 / 마진 유지하면서 고객 만족
✅ 기대결과
당일 계약 체결 + 고객 만족도 상 + 추천 고객 1명 확보 + 온라인 긍정 리뷰 작성
🔧 중고차 교환 고객 ⭐⭐⭐⭐⭐
50대 회사원, 중고차 매입가와 신차 가격 격차 조율 필요
📋 상황
50대 회사원, 5년 된 중형 세단(시세 1,200만원) 보유, 신형 SUV(견적 5,500만원)로 교환 희망. 중고차 상태 양호하나 사고 이력 1회(범퍼 교체). 고객은 1,500만원 교환가 요구, 당사 매입 기준 1,000만원. 대출 한도 3,000만원, 현금 부족.
🎯 목표
90분 협상으로 중고차 매입가 1,100만원 합의 + 대출 한도 3,500만원 확보 (제휴사 연계) + 부족분 900만원 할부 제안 → 총 5,500만원 계약 체결
⚡ 챌린지
사고 이력으로 인한 매입가 하락 설명 / 고객 기대 1,500만원 vs 현실 1,000만원 격차 / 대출 한도 상향 절차 복잡 / 할부 이자 부담 설득 / 경쟁사 더 좋은 조건 제시 가능성
✅ 기대결과
당일 계약 체결 + 중고차 1,100만원 매입 + 신차 5,500만원 판매 + 고객 만족 + 제휴 금융사 수수료 수익
✏️ 사용자 직접 입력
나만의 시나리오를 직접 작성
