STEP 1. 시나리오 선택

💡 사례 선택 가이드

1️⃣ 난이도 확인
⭐⭐⭐ 초급: 기본 상황
⭐⭐⭐⭐ 중급: 복잡한 변수
⭐⭐⭐⭐⭐ 고급: 위기 상황
2️⃣ 사례 읽기
상황·목표·챌린지를 꼼꼼히 읽고 실제 상황처럼 준비하세요
3️⃣ 카드 클릭
사례 카드를 클릭하면 선택됩니다. 이후 시나리오를 선택하고 녹음을 시작하세요
🎯 실전 팁
• 처음이라면 ⭐⭐⭐ 난이도부터 시작하세요
• 실제 업무와 유사한 사례를 선택하면 학습 효과가 높습니다
• 4번째 "나만의 실제 사례"는 본인이 직면한 실제 상황을 입력할 수 있습니다
• 녹음 전에 사례 내용을 2-3번 읽고 역할을 머릿속으로 리허설하세요

🎯 실전 상황별 상세 사례 (5배 확장 설명)

📱 신규 크리에이터 브랜딩 상담
난이도 ⭐⭐⭐
📋 상황 구독자 5천명 육아 유튜버가 수익화는 달성했으나 브랜드 정체성 부재로 성장 정체. 비슷한 콘텐츠의 경쟁 채널 다수. 협찬 제의는 있으나 단가가 낮고 브랜드 이미지와 맞지 않음.
🎯 목표 90분 상담으로 차별화 포인트 3가지 발굴 → 타겟 오디언스 재정의 → 콘텐츠 방향 수정안 제시 → 3개월 브랜딩 코칭 계약 300만원 체결
⚡ 챌린지 • 포화된 육아 카테고리에서 차별화 지점 발견
• 기존 구독자 이탈 없이 방향 전환
• 단기 수익 감소 우려 완화
• 크리에이터의 강점과 열정 재발견
✅ 기대결과 명확한 브랜드 아이덴티티 정립 + 3개월 후 구독자 1만명 달성 + 협찬 단가 2배 상승 + 고정 시청자층 확보
💰 PPL 협찬 계약 협상
난이도 ⭐⭐⭐⭐
📋 상황 100만 구독자 뷰티 인플루언서에게 화장품 브랜드가 2천만원 PPL 제안. 브랜드는 3편의 메인 콘텐츠 + 5편의 쇼츠 요구. 독점 계약 6개월 포함. 인플루언서는 금액은 만족하나 독점 조건과 콘텐츠 양에 부담.
🎯 목표 2시간 협상으로 광고비 2천5백만원 확보 + 독점 조건 3개월로 축소 + 메인 2편 + 쇼츠 3편으로 조정 + 2차 협찬 우선 협상권 확보
⚡ 챌린지 • 브랜드의 예산 한계 vs 인플루언서 부담 균형
• 독점 조건 완화 협상
• 콘텐츠 품질 유지하면서 물량 조정
• 장기 파트너십 전환 가능성 확보
✅ 기대결과 조건 개선된 계약 체결 + 브랜드 만족도 유지 + 2차 협찬 3천만원 확보 + 타 브랜드 협찬 기회 지속
🔥 위기관리 긴급 대응
난이도 ⭐⭐⭐⭐⭐
📋 상황 50만 구독자 게임 크리에이터가 과거 발언 논란으로 커뮤니티 폭발. 악성 댓글 1만개 이상, 구독자 1만명 이탈, 협찬사 2곳 계약 파기 통보. 본인은 충격으로 SNS 비공개 전환. 24시간 내 대응 필요.
🎯 목표 1시간 긴급 면담으로 사건 파악 → 3시간 내 대응 전략 수립 → 6시간 내 공식 입장문 + 사과 영상 제작 → 48시간 내 여론 반전 시나리오 실행
⚡ 챌린지 • 크리에이터의 심리적 패닉 진정
• 진정성 있는 사과 vs 과도한 사과 균형
• 협찬사 관계 회복
• 남은 구독자 이탈 방지
• 24시간 내 실행 가능한 액션 플랜
✅ 기대결과 48시간 내 악성 댓글 50% 감소 + 일주일 내 구독자 회복세 전환 + 한 달 내 협찬 재개 + 위기관리 사례로 브랜드 신뢰도 오히려 상승
