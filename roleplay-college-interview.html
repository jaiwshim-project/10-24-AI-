면접 시나리오를 선택하세요

📋 추천 사례

💡 사례 선택 가이드

1️⃣ 난이도 확인
⭐⭐⭐ 초급: 기본 상황
⭐⭐⭐⭐ 중급: 복잡한 변수
⭐⭐⭐⭐⭐ 고급: 위기 상황
2️⃣ 사례 읽기
상황·목표·챌린지를 꼼꼼히 읽고 실제 상황처럼 준비하세요
3️⃣ 카드 클릭
사례 카드를 클릭하면 선택됩니다. 이후 시나리오를 선택하고 면접을 시작하세요
🎯 실전 팁
• 처음이라면 ⭐⭐⭐ 난이도부터 시작하세요
• 실제 업무와 유사한 사례를 선택하면 학습 효과가 높습니다
• 4번째 "나만의 실제 사례"는 본인이 직면한 실제 상황을 입력할 수 있습니다
• 면접 전에 사례 내용을 2-3번 읽고 역할을 머릿속으로 리허설하세요
🎓 학생부종합전형
📍 상황: 리더십 활동 부족한 학생의 면접, 동아리 활동 위주 생기부 🎯 목표: 강점을 끌어내고 합격 판단 근거 확보 ⚡ 챌린지: 겉으로 드러나지 않는 역량 발견, 짧은 시간 내 평가 ✅ 기대결과: 학생 강점 발견 + 전공 적합성 확인 + 합격/불합격 근거 확보 난이도: ⭐⭐⭐
🌍 국제특기자 영어
📍 상황: 해외 경험 풍부한 학생의 영어 심층 면접, 영어로만 진행 🎯 목표: 진정성 검증 및 글로벌 역량 평가 ⚡ 챌린지: 스펙 과장 여부 판별, 영어 외 내면 평가 병행 ✅ 기대결과: 진정성 확인 + 글로벌 리더십 평가 + 입학 후 적응력 판단 난이도: ⭐⭐⭐⭐
🔬 과학 특기자
📍 상황: 과학 올림피아드 수상자의 전공 적합성 평가, 심화 질문 대응 🎯 목표: 암기 아닌 깊이 있는 이해도 확인 ⚡ 챌린지: 수상 배경 vs 실력 검증, 본인 연구 vs 외부 도움 구분 ✅ 기대결과: 실력 검증 + 연구 자세 평가 + 전공 발전 가능성 판단 난이도: ⭐⭐⭐⭐⭐

💡 추천 사례를 클릭하면 해당 시나리오가 자동으로 설정됩니다

선택한 언어로 AI가 대응합니다

🎯 지원동기 면접
"우리 대학(학과)에 지원한 동기는 무엇인가요?"
학교·전공 선택 이유와 진로 비전을 명확하게 전달하는 연습입니다.
📚 학생부 기반 면접
"생활기록부에 나온 '○○ 활동'에 대해 설명해주세요."
학생부의 구체적 활동을 깊이 있게 설명하는 연습입니다.
📖 제시문 기반 면접
"제시문을 읽고 요지를 요약하고 자신의 의견을 말씀해주세요."
논리적 사고와 비판적 분석 능력을 보여주는 연습입니다.
🔬 전공적합성 면접
"이 전공에서 가장 중요한 능력은 무엇이라고 생각하나요?"
전공에 대한 이해도와 학업 준비도를 입증하는 연습입니다.
⚕️ 의료윤리 면접
"의료진이 환자의 비밀을 지켜야 하는 이유는 무엇인가요?"
의학·간호 등 보건계열 지원자를 위한 윤리적 판단 훈련입니다.
✍️ 사용자 직접 입력
실제 예상 질문이나 과거 기출 문제를 직접 입력하여
맞춤형 면접 훈련을 진행할 수 있습니다.
